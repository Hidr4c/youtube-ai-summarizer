## 🚀 How to Upload to Chrome Web Store Developer Dashboard

1. Navigate to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
2. Select your extension item (or click **Add new item** and upload `youtube-summarizer-ai-v1.3.0.zip`).
3. Click on the **Store listing** tab in the left navigation sidebar.
4. Scroll down to the **Graphic assets** section:
   - **Store Icon** : Upload `store-icon-128x128.png`.
   - **Screenshots** : Click **Upload** and select all 4 screenshots (`screenshot-1` through `screenshot-4`).
   - **Small promotional tile** : Upload `promo-tile-small-440x280.png`.
   - **Marquee promotional tile** : Upload `promo-marquee-1400x560.png`.
5. Click **Save draft** and proceed to review.
