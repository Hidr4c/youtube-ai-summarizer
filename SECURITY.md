# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously.

If you discover a security vulnerability within YouTube Summarizer AI:

1. **Do not disclose it publicly** in a public issue or forum.
2. Please contact the author directly via GitHub security advisory or email at `hidrac1986@gmail.com`.
3. Provide a detailed summary with steps to reproduce the vulnerability.
4. We will acknowledge receipt within 48 hours and work with you to patch and release a fix promptly.
